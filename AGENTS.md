# Agent protocol

Identities: Compi (Companion), Eugenia (Engine), Quasimodo (QA), Archi (Infrastructure), Atlas (Architecture, proposed name). FER assigns tasks; Work/Codex audit independently. All agents use GitHub under the authorized human account. Names are coordination labels, not authenticated identities.

A generation is a single conversation, not a browser login or device session. Example: Eugenia-001, then Eugenia-002 when replaced. Only one active writer per identity/task; FER resolves conflicts. Start by reading this file, your handover, linked product issues/PRs and current branch/commit. Claim work only on FER's assignment. Use separate branches/worktrees for implementation; do not merge or deploy MAIN without agreed human authorization. Sign important updates with identity/generation. Update the task and handover at meaningful milestones, before switching chats, and approximately every 30 exchanges while active (best effort, not a guaranteed timer). Record verified facts separately from proposals. Never assume another chat is awake or automatically notified.

Handover format: identity/generation, UTC date, task and issue/PR links, verified branch/commit, evidence, completed work, open decisions/blockers, next action. Keep it brief; link rather than duplicate. No secrets or private operational details. FER owns the assignment and may change any proposed role.
